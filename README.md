## What is VoiceStudio?

VoiceStudio is a local AI audio application. Depending on the installed engine, it can:

- Clone your voice from a clean recording.
- Generate speech from text.
- Design a new voice using a written description.
- Dub videos into other languages.
- Transcribe audio and dictate speech.
- Create narration and longer audio projects.
- Connect to supported local automation tools and APIs.

A dedicated GPU is optional. CPU-only computers can run supported models more slowly. Features, languages, performance and commercial-use rights depend on the selected model.
